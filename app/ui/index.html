About Pseudo-Chrome

          
Pseudo-Chrome
Version 1.0.0
A local website demonstration utility.
Licensed under GNU AGPLv3.

          
Pseudo-Chrome presents a single local website with browser-style tabs and controls. Images, fonts, scripts and API requests may load from the internet when your website uses them.
General web browsing is disabled. Your website and its settings are stored on this computer.
Website-specific runtimes, databases and server rules must match the application you are demonstrating. Pseudo-Chrome does not compile backend source code.
